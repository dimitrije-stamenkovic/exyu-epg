# EX-YU EPG

XMLTV guide for the EX-YU channels of the IPTV playlist, published with
GitHub Pages. Guide channels are renamed to the exact channel names used in
`my_playlist.m3u`, so the player matches the guide by name.

Sources: epgshare01 `RS1`, `HR1`, `BA1`, `SPORTKLUB1` and the mts.rs channel API
(Serbian channels, ~1 day ahead; used where it has the fuller guide and as a
fallback when epgshare is down).

## Use

In the player (e.g. TiviMate) add the EPG URL:

    https://<github-user>.github.io/<repo>/epg.xml.gz

`report.txt` next to it lists which playlist channels got a guide.

## Files

| File | Purpose |
|---|---|
| `channels.txt` | Playlist channel names (+ tvg-id), generated by `sync_channels.py` |
| `overrides.txt` | Manual matches for names that differ between playlist and guide |
| `build_epg.py` | Downloads guides, matches channels, writes `public/` |
| `.github/workflows/epg.yml` | Builds and deploys daily at 01:00 Serbian time (CET/CEST) |

## Updating channel names

When the provider renames channels, refresh the playlist and re-sync:

    cd ../scripts && uv run xtream_to_m3u.py -s ... -o my_playlist.m3u
    cd ../exyu-epg && python sync_channels.py
    python build_epg.py --cache .cache   # check public/report.txt
    git commit -am "Sync channels" && git push

Channels listed as unmatched in `report.txt` that do have a guide can be
added to `overrides.txt` (`playlist name = guide channel id`). Guide ids are
listed in `report.txt` and in the source lists, e.g.
https://epgshare01.online/epgshare01/epg_ripper_RS1.txt

## Setup

1. Create a GitHub repo and push this folder to `main`.
2. Settings → Pages → Source: **GitHub Actions**.
3. Run the *Build EPG* workflow (or push); the URL appears in the run summary.
