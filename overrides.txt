# Manual matches for playlist channels whose names differ from the guide.
#
#   playlist channel name = guide channel id     (id as in public/report.txt
#                                                 or the epgshare01 .txt lists)
#   playlist channel name = -                    (never match this channel)
#
# Names are compared like the automatic matcher does: [tags], HD/TV/EXTRA
# etc. are ignored, but the country prefix must match, so "BA: BHT" covers
# "BA: BHT [1080p]" and "BA: BHT [EXTRA]  [1080p]" but not "RS: BHT".
